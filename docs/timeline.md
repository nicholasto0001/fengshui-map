## 三、撞過嘅牆（呢部分最有用）

### 數據

**元運攞咗最後一張入伙紙** — 樂生蓮社由 1969 年變成 2019 年，差五十年、差兩個運。
一幢樓有幾張入伙紙時，後面嗰啲係改建加建，**元運跟最早嗰張**。差餉物業估價署
自己份刊物都係咁做。

**座名唔係唯一嘅** — 「耀明樓」同時存在於耀東邨同華明邨，相距 24 公里。淨靠名配
就會配錯。而「第一座」「Ａ座」「二期」根本唔係名，係位置 —— 梨木樹二邨嘅「第一座」
配咗去 16 公里外。**解法：每個候選帶住屋邨座標，揀最近而且要喺 1.5 公里內。**

**房委會要配座名，唔係屋邨名** — 一座叫「德璋樓」，唔叫「德朗邨」。配屋邨名得 477
幢，配座名得 2,499 幢。

**元運只有三成係數據本身嘅限制** — 差餉物業估價署明言唔收錄村屋、政府物業、公屋
嘅落成年份。但呢個 30.3% 係計埋全港 213,328 幢建築物（連水泵房、變電站）。
**淨計地圖上當住宅顯示嗰 56,841 幢，有年份嘅係 92.2%。**

### 部署

**每次 push 兩分鐘後就上線** — 冇人睇過。喺 165,000 人嘅群組出 post 之前，
呢個係最危險嘅一件事。改成 `main → staging`，上線要另外撳掣。

**Cron 會繞過個審批** — GitHub 嘅 schedule 一定喺 default branch 上面跑，所以每晚
嘅數據更新會將 main 上面未審過嘅 code 推上線。改成 cron 去 checkout 已上線嗰個
branch：**新數據，舊（已審過）code。**

**靜態檔會蓋過 Worker** — Cloudflare 預設先出靜態檔，所以 `/` 直接配到 index.html，
個 Worker 永遠唔會行。要喺 `run_worker_first` 列明。而因為咁樣令**每個訪客**都經過
Worker，所以最外層包咗 try/catch —— 一張卡壞咗，唔可以連累成個首頁。

**Deploy 靜靜哋跌咗數據** — `bd_age.json` 係 gitignore 又唔喺 CI cache，但寫咗喺
「當日未 crawl 過先行」嗰步。所以同一日第二次 push 就冇咗屋宇署數據，元運由 30.3%
跌返 23.5%，而且**唔會報錯**。

**build.sh 用刪除清單就會漏嘢** — 「copy 成個 data/ 再刪幾個」令每個新嘅中間檔都出街，
`bd_age.json`（2.9 MB）一直 serve 緊俾全世界。改成 allowlist。

### 顯示

**紅→橙→綠過唔到色盲測試** — 相鄰色差喺 deuteranopia 之下只有 ΔE 2.6。拆走中間
嗰個琥珀色，改成紅↔青綠加低彩度中間點，色盲 19.9 / 正常 20.5（門檻 8 / 15）。

**一塊圖磚 1 MB** — 旺角嗰塊 z14 圖磚有 4,893 幢樓。均勻格網唔啱香港嘅形狀。改成
密嘅圖磚自動再切細，最大由 1,018 KB 跌到 241 KB。

**分區從來冇存過** — `o.district` 由頭到尾都係 undefined，所以撳一幢樓永遠只見英文名。
而家用 per-tile 索引（一個 byte 代替十一個 byte × 84,720 行）。

**單字黑名單會誤殺** — 一個「軍」字會剷走將軍澳，「中心」會剷走荃灣中心。擴闊之前
要對住十個已知屋苑測試過。

### 其他

**冇人偵測到截圖** — iOS Safari 同 Android Chrome 都冇呢個 API。唔扮做到，改為
「睇咗一幢樓 9 秒」就提示可以分享。

**同意唔可以係一個剔** — 要證明得到「邊個、幾時、同意邊個版本」。所以係一張只准
新增、唔准修改嘅紀錄表。改得嘅嘢唔算證據。

**生意數字唔可以喺 GA 攞** — GA 會抽樣、延遲、俾攔截器擋走 15–30%，而且條款禁止
同用戶紀錄夾埋。所以會員數、收入呢啲一律由自己個資料庫出。

## 四、貫穿全程嘅一個原則

風水係玄學，冇公認標準。所以：

- **寧願寫「未能起盤」，都唔砌一個睇落權威嘅假盤**
- 坐向係推算，誤差 ±10–20°，每次顯示都寫明唔係羅盤實測
- 對外講嘅覆蓋率要講用家真正見到嗰個數，唔係最好睇嗰個
- 所有數據來源可以追返去政府公開資料
