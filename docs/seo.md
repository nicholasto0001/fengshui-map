# SEO 計劃

寫於 2026-09-20。

---

## 一、現況：Google 幾乎乜都見唔到

實測 hkfengshuimap.com：

```
可見文字（去晒 script/style）   270 個字元
可以被索引嘅頁面               1 版
sitemap.xml                    冇（404）
robots.txt                     Cloudflare 預設嗰個，冇指向 sitemap
```

成個網站得 **270 個字**。84,720 幢樓、409 個屋苑、18 區嘅資料，Google 一個字都見唔到
—— 因為要行 JavaScript 先出到嚟，而爬蟲只攞到一個空殼。

**後果：** 有人 Google「頌真閣 風水」，你永遠唔會出現，雖然你係全香港唯一有呢個答案
嘅網站。

## 二、唔好追「風水」呢兩個字

搜「風水」排頭位嘅係麥玲玲、蘇民峰、媒體專題。佢哋有幾十年品牌、無數外部連結。
**追唔到，而且追到都唔係你要嗰班人** —— 搵「風水」嘅人可能想睇運程、想搵師傅，
唔一定喺度揀樓。

## 應該追嘅係呢三種

| 關鍵字 | 競爭 | 我哋有冇獨家內容 | 意圖 |
|---|---|---|---|
| **「XX屋苑 風水」** | **極低** | ✅ 409 個屋苑，冇人有 | **極高 — 正在揀緊呢個盤** |
| 「XX區 風水」 | 中 | ✅ 18 區排名 | 高 |
| 「香港風水地圖」 | 低（近乎品牌字） | ✅ | 高 |

搜尋實證：「日出康城 風水」排頭位嘅係 Facebook post、YouTube 片、個別師傅 blog。
**連最出名嘅樓盤都冇一個結構化嘅頁面**，其餘幾百個屋苑更加係空白。

## 三、要做嘅嘢：俾 Google 有嘢可以索引

核心改動：而家個 Worker 已經識喺 edge 改寫 OG，**同一個機制可以直接輸出真正嘅
HTML 內容**，唔使改成個架構。

### 第 1 層 — 地基（約 1 日）

- **自己嘅 robots.txt**，指向 sitemap
- **sitemap.xml**，由 pipeline 生成
- **首頁加真文字** —— 而家得 270 字，要有一段講清楚呢個網站係乜、數據嚟自邊、
  點計分。視覺上唔阻住個地圖，但喺 HTML 入面存在
- **Google Search Console** 驗證域名（呢步要你做）

### 第 2 層 — 18 個分區頁（約 1 日）

```
/d/大埔區
```

內容：該區平均分、樓宇數、大吉／吉／差嘅分佈、頭 50 名嘅樓宇連結、該區地理特點。

目標：「大埔 風水」「大埔區 風水好嘅屋苑」

### 第 3 層 — 409 個屋苑頁（約 2 日）

```
/e/日出康城
```

內容：屋苑名、座數、單位數、入伙年份、管理公司、每座嘅分數同飛星格局、
同區排名。

目標：「日出康城 風水」—— **呢一層係最值錢嘅**，意圖最強、競爭最低。

### 第 4 層 — 樓宇頁（約 2 日）

```
/b/<座標>/頌真閣
```

先做有名有姓、屬住宅、而且起到飛星盤嗰批（約 20,000 幢），唔好一次過出 84,720 版
—— Google 唔會全部收錄，而且大量薄內容頁會拖低成個網站嘅評價。

### 第 5 層 — 結構化資料

每版加 JSON-LD（`Place` / `Dataset` / `BreadcrumbList`），令 Google 明白呢版講緊
一個具體地點。

## 四、老實講嘅預期

**SEO 唔快。** Google 要爬、要索引、要建立信任：

| 時間 | 預期 |
|---|---|
| 第 1–2 星期 | Search Console 開始見到收錄 |
| 第 1–2 個月 | 長尾（屋苑名）開始有零星流量 |
| 第 3–6 個月 | 長尾穩定，分區字開始上到 |
| 第 6 個月以後 | 「香港風水地圖」應該排第一 |

**所以：出 post 帶嚟嘅流量會快好多。SEO 係長線資產，唔係下個禮拜嘅流量。**
兩樣要並行，唔好因為 SEO 慢就唔做 —— 佢係唯一唔使每次都靠推廣嘅流量來源。

## 五、唔好做嘅嘢

| 唔好做 | 點解 |
|---|---|
| 一次過出 84,720 版 | 大量薄內容會拖低成個網站評級 |
| 追「風水」呢兩個字 | 追唔到，而且意圖唔啱 |
| 買連結 / 交換連結 | Google 會罰，而且可以罰到成個域名 |
| 為咗塞關鍵字而寫廢話 | 用家一秒走人，Google 睇到跳出率 |
| 用 AI 大量生成「風水分析」文章 | 冇根據＝造假，同成個 app 嘅誠實原則衝突 |

最後一項要特別講：**每一版嘅內容都應該由真實數據生成**，例如「頌真閣，大埔區，
81 分，九運當運旺財，1969 年入伙」。呢啲係事實。唔好叫 AI 砌一段「此樓背山面水，
主財運亨通」出嚟 —— 嗰啲係假嘅，而且 Google 越嚟越識分。

## 六、順序

1. robots.txt + sitemap + 首頁文字 + Search Console ← **由呢度開始**
2. 18 個分區頁
3. 409 個屋苑頁 ← **最值錢**
4. 20,000 個樓宇頁
5. JSON-LD
