# 點樣變現，同埋可以攞啲乜資料

呢份答三條問題：我哋可以合法攞到啲咩、邊啲功能值得做、錢從邊度嚟。

---

## 一、法律先講清楚，因為呢條線一過就係刑事

香港《個人資料（私隱）條例》：

| 條文 | 講咩 | 對我哋嘅意思 |
|---|---|---|
| **s.35C** | 用個人資料做直銷，事前要明確告知 + 攞同意 | 電郵推廣要獨立 opt-in，個剔**唔可以預設剔咗** |
| **s.35J** | **收錢**將個人資料轉俾第三方做直銷 = **刑事**，最高罰 HK$1,000,000 + 監禁 5 年 | **賣 leads 俾師傅／地產代理，必須逐個攞書面同意**，唔可以「用戶登記即代表同意」 |
| DPP1 | 收集要有必要性，唔可以「攞埋先算」 | 未有理由就唔好問電話號碼 |
| DPP3 | 新用途要再攞同意 | 今日為「幫你搵樓」收嘅八字，聽日唔可以攞去賣保險 |

**最大風險唔係電郵，係屋企人嘅八字。**
佢老婆、佢阿仔嘅出生日期，係**第三者嘅個人資料**，而嗰個人冇同意過。
所以家庭 profile 要做，但要：
- 講明「你輸入屋企人資料，即係你話你有權咁做」
- 屋企人嘅資料**唔做直銷對象**，淨係用嚟計佢自己嗰份分析
- 一撳就刪得走，連埋成個 profile

## 二、可以攞到啲咩，同埋幾時先好問

| 資料 | 幾時問 | 值錢喺邊 |
|---|---|---|
| **電郵** | 登入嗰陣自動有（Google） | 唯一一個可以重複接觸嘅渠道。已經有。 |
| **屋企人數目同關係** | 建 profile 嗰陣 | **最值錢**：知佢係一家四口定單身，就知佢搵三房定開放式 |
| **小朋友年齡** | 由出生年推到 | 學區、預算、換樓時機 |
| **收藏／睇過邊啲樓** | 自動 | 知佢預算同心水地區，唔使佢講 |
| **電話號碼** | **淨係喺佢要求師傅聯絡佢嗰陣** | 冇理由就唔好問 —— 問咗會嚇走人，而且 DPP1 唔俾 |
| **預算** | 可以喺 profile 度問一條 | 直接分到 tier |

> 一個「一家四口、細路 6 歲同 9 歲、收藏咗沙田三房」嘅 profile，
> 價值遠高過一個電郵地址。而呢啲嘢係佢自己樂意填嘅 —— 因為填完
> 佢先睇到「呢個單位啱你全家」。

## 三、五條變現路，由最實際排落去

### 1. 收費報告（最快做到，最少法律風險）
一個單位一份完整分析：全家逐個人嘅八字夾唔夾、飛星盤、坐向、
周邊、成交價、可以 print 出嚟同屋企人傾。**HK$88–188 一份。**

點解可行：佢已經睇緊嗰個單位，已經投入咗，而且買樓係百萬級決定 ——
一百幾十蚊買個安心係最易過嘅一關。冇經常性成本，冇第三方。

### 2. 師傅推薦（收入最高，但要做足同意）
「想搵真人師傅睇？」→ 佢**主動**撳 → 逐次攞書面同意 → 轉介。
每個 lead HK$200–800（師傅一次上門收 $2,000–8,000）。

⚠ **s.35J**：收錢轉介個人資料做直銷係刑事。所以流程一定要係
「佢揀邊個師傅、佢撳制、佢同意」，唔可以係我哋派名單。

### 3. 訂閱（最穩定，但要夠多功能先撐得起）
HK$28–48／月：無限 profile、比較單位、新盤出咗夾你就通知、
儲低睇樓紀錄。**而家功能未夠厚，唔好住。**

### 4. 地產代理／發展商（數目最大，但唔可以賣人頭）
賣**總量統計**，唔賣個人資料：「你個盤有 62% 樓宇合九運格局，
高過同區平均」。呢啲係我哋本身就計到嘅嘢。
新盤廣告位亦得 —— 但要標明係廣告。

### 5. 聯盟（最低摩擦）
用戶睇中一個屋苑 → 跳去中原／美聯／28Hse 嗰個屋苑頁。
成交分成或者點擊費。我哋本身就有 678 版屋苑頁，天然接得上。

## 四、所以功能次序應該係咁

1. **家庭 profile**（名、關係、八字）→ 解鎖「呢個單位啱你全家」
   —— 呢個係其餘所有嘢嘅地基
2. **收費報告** → 第一舊錢，而且證明到有人肯俾錢
3. **師傅推薦** → 有咗 profile 同報告，轉介先有說服力
4. **通知**（新盤夾你）→ 有咗呢個先撐得起訂閱
5. **訂閱** → 最後先出

**唔好做：** 賣用戶名單、預設剔咗推廣、未問就收電話。
一次 s.35J 事故，成盤生意冇咗。
