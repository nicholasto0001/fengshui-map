# HK$500 廣告測試

寫於 2026-09-20。基於 2026 年香港嘅實際數據。

---

## 一、先算清楚 $500 可以買到咩

香港 Meta 廣告嘅實際成本（2026）：

| 受眾 | CPM（每千次曝光） |
|---|---|
| 廣泛 | HK$30–60 |
| 興趣定向 | HK$50–90 |
| 重定向（retargeting） | HK$80–150 |

**HK$500 用興趣定向 ≈ 6,000–10,000 次曝光 ≈ 60–200 個點擊。**

### ⚠️ 但有個問題要講清楚

業界建議：**每個 campaign 每日 HK$200–300 先做到有意義嘅測試**。
Meta 嘅學習期要**每星期約 50 個優化事件**先會穩定落嚟。

你嘅計劃係 **$500 用一個星期 = 每日 $71** —— 呢個會長期卡喺
「Learning Limited」，成本浮動大，數據係雜音。

**所以：唔好攤開一個禮拜。集中 2–3 日，每日 $170–250。**
同樣嘅錢，數據乾淨好多。

## 二、更重要嘅一件事：你有個免費渠道大過呢 $500 好多

```
HK$500 Meta 廣告  ≈  6,000–10,000 次曝光
你個 Facebook 群組 ≈  165,000 人，免費
```

**所以 $500 唔應該攞嚟買流量 —— 應該攞嚟做「文案測試」。**

用 $500 試三個唔同講法，睇邊個 CTR 最高，
**然後攞贏嗰個去寫你個群組嘅 post**。

咁樣 $500 買嘅唔係 200 個點擊，係一個可以用喺 165,000 人身上嘅答案。

---

## 三、渠道：Facebook，唔好用 Instagram

| | Facebook | Instagram |
|---|---|---|
| 香港成年人滲透率 | **約 72%** | 主要 18–35 歲 |
| CPM | 基準 | **貴 20–40%** |
| 買樓／風水受眾 | ✅ 年齡吻合 | ❌ 偏後生 |
| 你已有嘅資產 | ✅ 165K 群組 | ❌ 冇 |

**結論：Facebook feed 為主。** 揀 placement 嗰陣可以留 Advantage+
自動版位（佢會自己分配），但唔好特登主攻 IG。

## 四、素材：拍片，唔好淨係出圖

**數據：影片嘅 CPM 比靜態圖平 15–25%。** 同樣嘅錢多 20% 曝光。

### 但唔使搞製作 —— 最好嗰條片就係螢幕錄影

```
0–3 秒   打「和喜樓」落搜尋欄
3–6 秒   地圖飛過去，成片樓宇上曬色
6–10 秒  撳一撳，分數彈出嚟：49 分
10–15 秒 向下捲，見到飛星盤
```

**15 秒，用電話錄，唔使剪輯。**

點解有效：佢同時係**廣告**同**示範**。人睇完就知個 app 係乜、點用、
有幾快 —— 呢啲嘢用一張圖講唔到。

### 規格

| | |
|---|---|
| 比例 | **4:5**（直度，feed 最大面積）或 9:16（Reels） |
| 長度 | 10–15 秒 |
| 開頭 | 頭 3 秒一定要見到「打名 → 出分數」 |
| 字幕 | 要有（大部分人靜音睇） |
| 語言 | **廣東話，唔好用書面語，更加唔好用英文** |

研究明確指出：香港**廣東話口語文案嘅表現遠勝直譯**，
機器翻譯嘅內容表現最差。

### 三條文案（就係要測試嘅三樣嘢）

| 版本 | 角度 | 文案 |
|---|---|---|
| **A** | 自己 | 你住緊嗰幢樓，風水幾多分？打個名就知。 |
| **B** | 八卦 | 你朋友住嗰度幾多分？打個屋苑名就睇到。 |
| **C** | 數據 | 全港 84,720 棟樓宇，每棟都有九運風水評分。政府公開數據計算。 |

**B 係重點測試對象。** Zillow 嘅研究顯示，人對「別人間屋」嘅好奇
唔輸過對自己間屋，而且「別人間屋」先係可以攞出嚟講嘅。

## 五、設定：一步一步

### 開始之前要有嘅兩樣

1. **一個 Facebook 專頁（Page）** —— ⚠️ **群組唔得**。Meta 廣告一定要用專頁做身份。
   如果未有就要開一個（免費，十分鐘）。
2. **Meta Pixel 裝咗喺網站度** —— 就算今次唔用轉換目標，
   都要裝。因為 pixel 一日唔裝，一日都儲唔到重定向受眾，
   而重定向係之後最平最準嘅受眾。

### Campaign 設定

| 項目 | 揀咩 | 點解 |
|---|---|---|
| **目標** | **Traffic（流量）** | 唔好揀 Conversions —— $500 儲唔到 50 個轉換事件，學習期出唔到 |
| **優化** | **Landing page views** | 唔係「連結點擊」。咁樣唔使為手震撳到嘅人俾錢 |
| **預算** | **每日 HK$200，行 2–3 日** | 唔好每日 $71 行 7 日 |
| **Campaign 數** | **1 個** | 最常見嘅錯係分開五個細 campaign。唔好分散 |
| **Ad set 數** | **1 個** | |
| **廣告數** | **3 個**（A/B/C 文案） | 同一個 ad set 入面，Meta 自己會分配 |
| **預算方式** | **ABO**（ad set 層級） | 測試階段要每個變體都攞到數據 |

### 受眾

```
地點      香港
年齡      28–60
語言      不限（唔好限死）
興趣      風水 OR 置業 OR 地產 OR 玄學 OR 室內設計
```

**點解用興趣唔用廣泛：** 廣泛 CPM 平啲（$30–60 vs $50–90），
但你只有 $500，**準確度比平重要**。

### 開咗之後

⚠️ **唔好中途改嘢。** 改受眾、改預算超過 20%、加減廣告、改優化目標 ——
**全部都會重置學習期**，你嗰 $500 就白費。

開咗就唔好郁，睇完先算。

## 六、應該睇咩數字

$500 答唔到「一個用戶值幾錢」，但答得到**「邊個講法最多人撳」**。

| 指標 | 好嘅話 | 意思 |
|---|---|---|
| **CTR（連結點擊率）** | > 1.5% | 文案啱唔啱 |
| **每次 landing page view 成本** | < HK$3 | 有冇效率 |
| **A/B/C 邊個贏** | —— | **呢個先係 $500 真正買到嘅嘢** |
| GA：每 session 睇幾多幢樓 | > 3 | 落到嚟嘅人有冇玩落去 |
| GA：跳出率 | < 60% | 條片有冇呃人入嚟 |

**然後攞贏嗰個文案去寫你個群組嘅 post。**

## 七、唔好做

| 唔好做 | 點解 |
|---|---|
| 每日 $71 行成個禮拜 | 卡喺學習期，數據係雜音 |
| 分開幾個 campaign | 預算分散，每個都學唔到嘢 |
| 揀 Conversions 目標 | $500 儲唔夠 50 個事件 |
| 中途改設定 | 重置學習期，錢白花 |
| 用英文或者書面語 | 香港廣東話口語文案表現遠勝 |
| 主攻 Instagram | CPM 貴 20–40%，而且受眾偏後生 |
| 未裝 pixel 就落廣告 | 之後重定向冇受眾可以用 |
