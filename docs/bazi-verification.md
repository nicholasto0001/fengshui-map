# 八字排盤：核對報告

AI 排盤唔準，唔係因為八字難，係因為**模型喺度估，唔係喺度計**。排盤
由頭到尾都係算術：六十甲子循環 + 節氣界線，冇一步需要判斷。所以解法
唔係叫模型小心啲，係**根本唔俾模型計** —— 寫程式計，再攞外面嘅權威
來源逐個對。

呢份係對過乜、結果點。

---

## 一、節氣（年柱同月柱嘅界線）

年柱喺**立春**轉，月柱喺十二個**節**轉。兩者都係天文時刻，唔係日曆日期。

**第一次寫，用 Meeus 簡化式。** 同天文台對，每個節氣都早咗 7–13 分鐘。
呢個同理論吻合（嗰條式準到 0.01°，即係 ±15 分鐘），但**立春爭十分鐘
可以換成個年柱**，所以唔夠用。

**改用 VSOP87 截斷級數。** 準到大約 0.001°，即係一分半鐘。

### 對照結果

| 對照 | 數量 | 結果 |
|---|---|---|
| 天文台《公曆與農曆對照表》1901–2100，節氣**日期** | 4,800 | 唔同 **6 個** |
| 天文台節氣時刻 XML（2019–2028），**逐分鐘** | 220 | 206 個完全一致，**最大差 1 分鐘** |

**嗰 6 個唔同嘅：**

```
1912 小雪（氣）  我哋 11-22 23:48   天文台 11-23   離午夜 12 分鐘
1913 秋分（氣）  我哋 09-23 23:53   天文台 09-24   離午夜  7 分鐘
1917 大雪（節）  我哋 12-08 00:01   天文台 12-07   離午夜  1 分鐘
1923 雨水（氣）  我哋 02-20 00:00   天文台 02-19   離午夜  0 分鐘
1927 白露（節）  我哋 09-09 00:05   天文台 09-08   離午夜  5 分鐘
1928 夏至（氣）  我哋 06-22 00:07   天文台 06-21   離午夜  7 分鐘
```

全部喺 1950 年之前，全部踩正午夜前後十五分鐘之內。**1950 年之後
2,400 個節氣零差異。**

點解斷定係天文台嗰批戰前數據，唔係我哋條算式：近午夜嘅節氣喺各年代
平均分佈（每 25 年 10–16 個）。如果係我哋差幾分鐘，錯誤會平均散開,
唔會全部擠喺頭五十年。戰前嗰批係當年用舊曆表推算嘅。

對八字影響更細：換月柱只用十二個「節」，六個入面得兩個係節，兩個都
喺 1930 年前。

### 核對途中捉到嘅真 bug

1923 雨水啱啱好落喺 **00:00:00**。原本嘅寫法係先轉公曆再四捨五入分鐘,
撞正午夜就 round 到 1440 分鐘，跟住嗰段特別處理**推多咗一日**。
改成先將儒略日對齊到分鐘，再轉公曆，就冇呢個 case。

### 核對途中捉到嘅第二個真 bug

第一次同外面對，日柱**早咗一日**。原因：`jd_from(y, m, d+0.5)` 出嚟
嗰個中午儒略日**本身已經係 JDN**，我多加咗個 1。

**呢個 bug 排出嚟個盤照樣似模似樣** —— 年柱月柱啱、五鼠遁五虎遁都對、
內部完全自洽。淨係睇輸出係一世都睇唔出嚟嘅，一定要同外面對先知。

## 三、最重要嘅發現：晚子時冇統一答案

夜晚 11 點到 12 點出世點排，**三個實作三個答案**：

| | 日柱 | 時柱 |
|---|---|---|
| 子時起新日 | 轉下一日 | 跟下一日 |
| 晚子時（bz.superd.org）| 留當日 | 跟當日 |
| lunar-python | 留當日 | **跟下一日** |

呢個唔係邊個計錯，係門派分歧。而各家軟件**靜靜雞揀咗一個，都冇講**。

影響幾多人：出生時間喺 23:00–23:59 嗰啲，即係**二十四分一**。

我哋三種都支援，而且凡係呢個時段都會喺盤上面講明用咗邊一種。

## 四、節氣嗰一分鐘

生喺節氣本身嗰一分鐘嘅人，我哋同 lunar-python 有 425 個唔同（7,200 個
測試點入面）。

呢度冇一方係權威：我哋嘅節氣準到大約一分鐘，人哋嗰個都係計出嚟嘅。
所以合格線唔係「同佢一模一樣」，而係：

> **有分歧嘅個案，我哋一定要自己講咗「呢個位唔肯定」。**

結果：**425 個分歧，425 個都有標示，零個係靜靜雞唔同。**

## 五、仲未決定嘅：真太陽時

香港喺東經 114.17°，但用緊東經 120° 嘅時區 —— 差 **23 分鐘**。再加
均時差（一年入面 -14 到 +16 分鐘），最多可以差成 **39 分鐘**。

夠唔夠換時柱？夠。每個時辰兩個鐘，39 分鐘足以令生喺時辰頭尾嘅人換咗
成個時柱。

**但我哋核對過嘅網站同 lunar-python 全部都冇校正。** 傳統師傅有人校、
有人唔校。

程式兩樣都做得到（`true_solar=True/False`），但**預設用邊個要你決定**,
因為呢個會令我哋同市面大部分排盤工具出唔同結果。
