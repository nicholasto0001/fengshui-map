# 點樣傳得開

寫於 2026-09-20。基於三個同類產品嘅實際研究，唔係空想。

---

## 一、參考咗邊三個，學到啲乜

### Zillow「Zestimate」— 睇樓價

**最重要嗰個發現，而且同我哋而家嘅定位相反。**

研究講得好白：人係八卦嘅，**唔止想知自己層樓值幾錢，仲好想睇朋友、外父外母層樓值幾錢**。
Zillow 靠呢樣嘢喺推出第一年就變成全美國流量最高嘅網站之一。

> 我哋而家成個 app 嘅文案都係「**你**屋企幾多分」—— 全部對住自己。
> 但真正令人傳出去嘅，可能係「**睇下你外父屋企幾多分**」。

第二點：Zillow 明知個估價唔準，但佢哋清楚**參與度比精準度重要**。我哋唔會學佢
扮準（呢個係底線），但可以學佢**降低查詢門檻到幾乎零**。

### Spotify Wrapped — 年度回顧

六個心理機制入面，最關鍵三個：

| 機制 | 對我哋嘅意思 |
|---|---|
| **身份認同** | 人 share 嘅係「呢樣嘢代表我」。一個分數要變成一句自我介紹 |
| **共同創作** | 啲數據係「你嘅」，所以你有擁有感。一幢你揀咗做「我屋企」嘅樓，同一幢隨便撳嘅樓，完全兩回事 |
| **時機** | Wrapped 喺年尾出，因為嗰陣全世界本來就喺度回顧。**香港嘅對應時機係農曆新年同立春** |

### Co-Star — 星座 App

佢嘅爆發**唔係**靠每日運程，係靠**「同朋友比較」**：加咗朋友就即刻出一張合盤，
拆解「溝通」「情緒」等等。**要加朋友，你就要叫佢入嚟。**

留存方面靠推送通知 —— 短、貼身、每日。

## 三、可以做嘅嘢（由最抵做排落去）

### 🥇 1. 加「排名」—— 最平、最快、最有效

每幢樓加兩個數：

```
新蒲崗大廈  75 分
　黃大仙區排第 312 / 1,539
　全港排第 2,841 / 56,841
```

**點解有效：** 分數係抽象嘅，排名係具體嘅。人會 share 排名，唔會 share 分數。
而且「你嗰區排第幾」直接製造地區話題。

**成本：** 數據已經有，計一次排序就得。半日。

---

### 🥈 2.「我屋企」—— 身份錨點 + 回訪理由

俾用戶指定一幢樓做「我屋企」。之後：

- 開 app 第一眼見到佢
- 有張專屬嘅卡：「我屋企 81 分，贏全港 99%」
- **立春流年一變，可以話返俾佢知**

**點解有效：** Spotify Wrapped 嘅「共同創作」機制。一幢你認咗做屋企嘅樓，
你會有擁有感，會想 share。隨便撳嘅樓唔會。

**成本：** 會員系統已經有，加一個欄位。一日。

---

### 🥉 3. 排行榜 ——「全港十大旺宅」

```
全港十大旺宅
各區之冠（18 個）
九運最多「旺山旺向」嘅屋苑
入囚最多嘅區
```

**點解有效：** 榜單天生好 share，而且**全部係真數據**，唔使砌。
順便一箭雙鵰 —— 呢啲正正就係 SEO 第二階段要嘅分區頁同屋苑頁。

**成本：** 一至兩日，而且同 SEO 工作重疊。

---

### 4. 兩幢樓 PK

揀兩幢樓，並排比較，出一張對照卡。

**點解有效：** 比較係 Co-Star 真正嘅爆發點。而且「A 同 B 邊個好？」
天生製造爭論 —— 爭論就係傳播。

**成本：** 兩至三日（要新嘅卡版面）。

---

### 5. 立春流年推送

每年立春流年飛星會變，**呢個係真嘅**，唔係砌出嚟嘅理由。

```
立春到咗，你屋企今年嘅飛星變咗。
```

**點解有效：** Wrapped 嘅時機原則 + Co-Star 嘅推送留存。而且農曆新年前後，
全香港本來就喺度講運程 —— 撞正個話題已經存在嘅時候出現。

**成本：** 要有 email 名單（同意剔格已經喺登入度），加一年一次嘅發信。

⚠️ **一年一次得。流月都會變，但每月推送就會由「有用」變成「呃人」。**
嗰條線唔好過。

---

### 6. 八字夾唔夾（Phase 2/3）

Co-Star 嗰招，原封不動搬過嚟：

- 輸入八字 → 呢間屋夾唔夾你
- **加家庭成員 → 你要問老婆、阿爸攞出生資料 → 佢哋就會入嚟**

**內建邀請機制**：你冇得一個人完成，一定要拉人入嚟。

## 四、文案要改嘅方向

而家全部係「**你**屋企幾多分」。加多一條線：

| 而家 | 可以加 |
|---|---|
| 睇下你屋企幾多分 | **睇下你外父屋企幾多分** |
| 你揀緊嘅樓盤 | **你朋友住嗰度，你估幾多分？** |
| | **成個屋苑邊一座最旺？** |

Zillow 嘅研究講明：人對**別人**間屋嘅好奇，唔輸過對自己間屋。
而「自己間屋」係私密嘅，「別人間屋」先係可以拎出嚟講嘅。

## 五、唔好做嘅嘢

| 唔好做 | 點解 |
|---|---|
| 每日推送 | 冇人日日查自己層樓風水。日日推 = 變垃圾 |
| 打卡、連續登入獎勵 | 呢個唔係日拋型產品，硬砌習慣會好假 |
| 扮準、扮權威 | 同成個 app 嘅誠實原則衝突，一被拆穿就冇曬信用 |
| 逼人分享先睇到結果 | 反感，而且會殺死口碑 |
| 抽獎、俾錢叫人 share | 引嚟嘅唔係真用戶 |
