# 地區屬性：查咗啲乜，結論係乜

用戶要求：搵有信譽嘅師傅講唔同地區嘅五行屬性，建立一個屬性資料庫。
呢份記低搵到啲乜、點解最後唔係咁做、同埋改為做咗乜。

---

## 一、五行屬性：冇權威清單

搵過：蘇民峰、李丞責、麥玲玲、楊天命、宋韶光，同埋幾份坊間清單。

**冇一位有完整嘅十八區五行表。**

唯一有清單嗰個係 `istream.cc` 2011 年一篇標住「摘錄」嘅匿名網誌：

```
九龍／新界：東木＝將軍澳西貢觀塘彩虹黃大仙九龍城
            南火＝馬頭圍土瓜灣紅磡尖沙咀佐敦
            中土＝旺角太子九龍塘何文田沙田
            西金＝深水埗至屯門
            北水＝元朗上水粉嶺大埔
港島：      東木＝柴灣至寶馬山 · 南火＝香港仔淺水灣
            中土＝半山 · 西金＝上環至華富 · 北水＝北角至中環
```

**三個問題：**

1. **自己矛盾。** 上環屬金、中環屬水 —— 但兩者同屬中西區。我哋嘅數據單位
   係十八區，根本表達唔到。
2. **來源之間唔同。** 區晉豪話「新界屬北（水）」，仲特別講「要火就揀新界
   偏南，例如馬鞍山、沙田」；istream 話「沙田屬中土」。同一個沙田兩個答案。
3. **唔完整。** 嗰篇文下面十四年嘅留言：「油麻地屬咩？」「跑馬地呢？」
   「荃灣屬咩？」「黃埔屬咩？」—— 冇人答得到。

我自己用同一條規則（方位）計十八區，同 istream 嗰份對：**8 啱 4 錯**。

**結論：唔出「某區屬某五行」嘅標籤。** 改為講方位 —— 「你喜火，火對應南方，
以下係香港偏南嘅區」。呢個係兩位師傅都用嘅框架，而且覆蓋到全香港。

## 二、搵到更好嘅：九運「南山北水」

白鶴鳴風水專業學院講師匡正師傅，2025 年 5 月：

> 九運以「**南山北水**」嘅風水格局最為吉利，只要地域區中「南方見山、
> 北方見水」…又稱「離山坎水」，係丁財兩旺嘅理想格局。

另一篇（同一學院）講得更細：九運宜居 —— **南方見山**，或者**北方見水**，
東南見水為次選。

### 呢個可以直接驗證我哋個評分

我哋個 MWDS 表係由 **2023 年政府風水地圖圖層逆向工程**出嚟嘅，同呢位師傅
完全冇關係。而最高分嗰行係：

```
MWDS 9  山喺南 / 水喺北     ← 南山北水
```

**兩邊獨立吻合。**

數據入面：南山北水嘅住宅得 694 幢（1.2%），平均 **75.3 分**，
全港住宅平均 50.9 分。

（留意：MWDS 8（北山南水）嘅總平均係 78.8，高過 MWDS 9。呢個唔係矛盾 ——
總分仲包括山水距離同配套，而 MWDS 8 得 313 幢，樣本細而且啱啱好其他條件
都好。MWDS 分項本身係 9 > 8。）

### 更有力嘅驗證：師傅點名嗰啲區

匡正師傅點名九運風水好嘅：港島北（中環、銅鑼灣、灣仔）、半山、山頂、
上水、粉嶺、馬鞍山、天水圍、元朗、大嶼山北岸。
要小心嘅：九龍東（觀塘、黃大仙）、港島南（赤柱、石澳）。

我哋用自己嘅地形數據計「住宅入面有幾多幢係南方見山**或者**北方見水」：

| 區 | 比例 | 佢點名 |
|---|---|---|
| 東區 | 97% | ✓ 好 |
| 中西區 | 90% | ✓ 好 |
| 灣仔區 | 78% | ✓ 好 |
| 北區 | 74% | ✓ 好 |
| 沙田區 | 67% | ✓ 好 |
| 元朗區 | 67% | ✓ 好 |
| 離島區 | 62% | ✓ 好 |
| … | | |
| 黃大仙區 | 50% | ⚠ 要小心 |
| 觀塘區 | 34% | ⚠ 要小心 |
| 油尖旺區 | 34% | |

**佢點名「好」嗰七個區，喺我哋數據入面排頭七；佢話要小心嗰兩個，排尾。**

兩邊完全獨立：佢用傳統方法睇地形，我哋用政府地理數據計最近山水嘅方位。

## 四、再查一次（2026-09-22）：搵齊成套，然後用嚴格條件重測

上面第二節用嘅係**寬鬆條件**：「南方見山 **或者** 北方見水」，拎到 7/7 吻合。
今次搵齊咗同一學院成套四篇文，再用**嚴格條件**（南方見山 **同埋** 北方見水）
重新計過。兩個都係合理嘅測法，但答案唔同，而唔同嗰度先有嘢學。

### 嚴格條件下全港係咁

53,637 幢住宅：

| | 佔比 |
|---|---|

**呢個數字對產品好緊要。** 理想格局全港得 18.7% 做得到，犯忌嗰批仲多過佢。

三個唔啱嘅位，每個原因唔同，值得分開講：

**荃灣 —— 同一篇文自己打自己。** 荃灣嘅水喺西南（1,112 幢入面 962 幢），
山喺東北，即係**北山南水**。而同一篇文入面，佢判深井（隔離兩公里、
同一個地形）「北山南水，在九運大忌…水鬼上山及山神困水」。同一個格局，
兩個相反結論。

**尖沙咀 —— 佢轉咗用第二套講法。** 尖沙咀嘅水由西南兜到東南（維港），
山喺西同南。按「南山北水」係唔合格嘅，佢自己都寫「面向大海，**按理來說
風水不佳**」，跟住用「**玉帶環腰水**」呢個另一個概念救返。公道講，維港真係
兜住尖沙咀，「玉帶環腰」形容得啱。但咁即係話：**佢個結論唔係由佢自己
開頭嗰條規則計出嚟。**

**淺水灣 —— 地形講錯咗。** 佢話「南方見山」。實測淺水灣啲山主要喺西北
（紫羅蘭山一帶），水喺西南同東南。不過淺水灣嘅**總分**係呢批地點最高
（55.6）—— 因為山水都近、避煞好。呢個正好示範點解我哋要分開「風水」
同「大運」兩條數：格局唔合九運，唔代表個地方唔好住。

### 呢啲代表咩

1. **條規則係真嘅，而且計得到。** 半山 37.9% 全港最高、觀塘／黃大仙包尾 ——
   同師傅講法一致。我哋個 MWDS 表逆向工程自政府圖層，同佢完全冇關係，
   兩邊獨立吻合。
2. **但師傅逐個地方嘅判語，唔一定由自己條規則推出嚟。** 十個點名地點，
   七個對得上，三個相反 —— 而三個都係海景靚嗰啲。
3. **所以我哋唔應該抄佢個排名，應該出返我哋自己量到嘅嘢，同時講明
   邊度同師傅講法唔同。** 呢個係我哋唯一做得到、而佢哋做唔到嘅事：
   五萬幾幢樓逐幢量，量完敢講邊度對唔上。

⚠ 一句要寫明嘅限制：我哋量嘅係**最近**嗰座山同**最近**嗰笪水嘅方位，
唔係「有冇靠山」嘅整體形勢。深井我哋個框只圈到 34 幢，樣本太細，
所以上面冇攞佢落表比較。

## 五、樓層五行：兩個學派，答案唔同

用戶想喺解鎖內容入面講「你應該住幾樓」。查完結論係：**唔可以淨係講一套。**

**A. 九星配樓層**（白鶴鳴學院，匡正師傅，2019-03-23，
[原文](https://www.hokming.com/)，Big5 編碼）

```
1樓=一白水  2=二黑土  3=三碧木  4=四綠木  5=五黃土
6=六白金    7=七赤金  8=八白土  9=九紫火    之後每 9 層一循環
```
文中例子：弱火命喜木火 → 3、4、12、13 樓；強火命喜金水 → 1、6、7、10 樓。

**B. 河圖數配樓層**（坊間通用）

```
1、6 屬水   2、7 屬火   3、8 屬木   4、9 屬金   5、10 屬土
```

**兩套打架：**

| 樓 | 九星派 | 河圖派 |
|---|---|---|
| 2 | 土 | **火** |
| 6 | 金 | **水** |
| 7 | 金 | **火** |

最值得留意嘅係：**A 篇嘅作者自己第一句就寫「不同風水派別在看風水時，
有不同的推算樓層五行方法」。** 即係連提出者都冇當佢係唯一答案。

另外查到有評論直指「數字五行論不靠譜」，亦有講法話樓層五行相對
外部形勢同室內格局只係「次要因素」。

**做法：唔揀邊一派。** 要出就兩套並列，講明邊個師傅用邊套、佢哋自己都
承認唔統一。呢個同我哋處理「寒熱命 vs 扶抑用神」嘅做法一致 ——
坊間軟件淨係出一個數，我哋出分歧，因為分歧係真嘅。
