# 地區屬性：查咗啲乜，結論係乜

用戶要求：搵有信譽嘅師傅講唔同地區嘅五行屬性，建立一個屬性資料庫。
呢份記低搵到啲乜、點解最後唔係咁做、同埋改為做咗乜。

---

## 一、五行屬性：冇權威清單

搵過：蘇民峰、李丞責、麥玲玲、楊天命、宋韶光，同埋幾份坊間清單。

**冇一位有完整嘅十八區五行表。**

唯一有清單嗰個係 `istream.cc` 2011 年一篇標住「摘錄」嘅匿名網誌：

```
九龍／新界：東木＝將軍澳西貢觀塘彩虹黃大仙九龍城
            南火＝馬頭圍土瓜灣紅磡尖沙咀佐敦
            中土＝旺角太子九龍塘何文田沙田
            西金＝深水埗至屯門
            北水＝元朗上水粉嶺大埔
港島：      東木＝柴灣至寶馬山 · 南火＝香港仔淺水灣
            中土＝半山 · 西金＝上環至華富 · 北水＝北角至中環
```

**三個問題：**

1. **自己矛盾。** 上環屬金、中環屬水 —— 但兩者同屬中西區。我哋嘅數據單位
   係十八區，根本表達唔到。
2. **來源之間唔同。** 區晉豪話「新界屬北（水）」，仲特別講「要火就揀新界
   偏南，例如馬鞍山、沙田」；istream 話「沙田屬中土」。同一個沙田兩個答案。
3. **唔完整。** 嗰篇文下面十四年嘅留言：「油麻地屬咩？」「跑馬地呢？」
   「荃灣屬咩？」「黃埔屬咩？」—— 冇人答得到。

我自己用同一條規則（方位）計十八區，同 istream 嗰份對：**8 啱 4 錯**。

**結論：唔出「某區屬某五行」嘅標籤。** 改為講方位 —— 「你喜火，火對應南方，
以下係香港偏南嘅區」。呢個係兩位師傅都用嘅框架，而且覆蓋到全香港。

## 二、搵到更好嘅：九運「南山北水」

白鶴鳴風水專業學院講師匡正師傅，2025 年 5 月：

> 九運以「**南山北水**」嘅風水格局最為吉利，只要地域區中「南方見山、
> 北方見水」…又稱「離山坎水」，係丁財兩旺嘅理想格局。

另一篇（同一學院）講得更細：九運宜居 —— **南方見山**，或者**北方見水**，
東南見水為次選。

### 呢個可以直接驗證我哋個評分

我哋個 MWDS 表係由 **2023 年政府風水地圖圖層逆向工程**出嚟嘅，同呢位師傅
完全冇關係。而最高分嗰行係：

```
MWDS 9  山喺南 / 水喺北     ← 南山北水
```

**兩邊獨立吻合。**

數據入面：南山北水嘅住宅得 694 幢（1.2%），平均 **75.3 分**，
全港住宅平均 50.9 分。

（留意：MWDS 8（北山南水）嘅總平均係 78.8，高過 MWDS 9。呢個唔係矛盾 ——
總分仲包括山水距離同配套，而 MWDS 8 得 313 幢，樣本細而且啱啱好其他條件
都好。MWDS 分項本身係 9 > 8。）

### 更有力嘅驗證：師傅點名嗰啲區

匡正師傅點名九運風水好嘅：港島北（中環、銅鑼灣、灣仔）、半山、山頂、
上水、粉嶺、馬鞍山、天水圍、元朗、大嶼山北岸。
要小心嘅：九龍東（觀塘、黃大仙）、港島南（赤柱、石澳）。

我哋用自己嘅地形數據計「住宅入面有幾多幢係南方見山**或者**北方見水」：

| 區 | 比例 | 佢點名 |
|---|---|---|
| 東區 | 97% | ✓ 好 |
| 中西區 | 90% | ✓ 好 |
| 灣仔區 | 78% | ✓ 好 |
| 北區 | 74% | ✓ 好 |
| 沙田區 | 67% | ✓ 好 |
| 元朗區 | 67% | ✓ 好 |
| 離島區 | 62% | ✓ 好 |
| … | | |
| 黃大仙區 | 50% | ⚠ 要小心 |
| 觀塘區 | 34% | ⚠ 要小心 |
| 油尖旺區 | 34% | |

**佢點名「好」嗰七個區，喺我哋數據入面排頭七；佢話要小心嗰兩個，排尾。**

兩邊完全獨立：佢用傳統方法睇地形，我哋用政府地理數據計最近山水嘅方位。
